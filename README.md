# AI tools and content experiments

Эксперименты и рабочие инструменты по нейросетям в контент-продакшне — от ИИ-агента монтажа до агентов для контента и маркетинга.

**EN:** Experiments and working tools for AI in content production by Ozge media (Astana, Kazakhstan): an AI video-editing agent, an auto-editing pipeline for talking-head videos and shorts, and Claude-based agents for content and marketing.

▶️ **Видео-демо ИИ-агента монтажа:** https://youtu.be/GARec2zQ-ng

Акжаркын Куздибаева, основатель контент-студии Ozge media (Астана).

## Проекты

| Проект | Что делает | Стек |
|---|---|---|
| **[montage-agent](https://github.com/OZGE-ai/montage-agent)** | ИИ-агент монтажа интервью на 3 камеры и видеоуроков: синхронизация камер по звуку, вырезка пауз и «э-э», выбор камеры по взгляду говорящего, перебивка в стиле The Diary Of A CEO, плашки, субтитры ru → kk. Правки заказчика превращает в проверяемые правила. Демо и тесты внутри | Python, faster-whisper, MediaPipe, FFmpeg, Claude Code |
| **[montage-pipeline](https://github.com/OZGE-ai/montage-pipeline)** | Автомонтаж «говорящей головы» и шортсов: транскрипт и дубли → разметка вырезок агентом → рендер в Remotion с зумами на лицо, акцентными словами и караоке-субтитрами. Плюс сценарии, генерация b-roll и тексты для публикации | Python, Remotion (React/TS), Deepgram, MediaPipe |
| **[ozge-ai-agents](https://github.com/OZGE-ai/ozge-ai-agents)** | ИИ-агенты (навыки Claude): контент-движок, сценарист рилсов и сторис, маркетолог эксперта, раздатка для учителя. Веб-приложения: дашборд воронки мастер-класса и «личная ОС для работы с ИИ» | Claude skills, HTML/CSS/JS |
